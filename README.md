# 简历罗盘 · Resume Beautify

> AI 简历润色网站的设计原型集合 —— 从需求规划到视觉方案的完整沉淀，可直接用 Docker 一键起站预览。

一句话定位：**不是把简历润色得更好看，而是让它精确落到招聘方划的那条线上。**

---

## 这是什么

本仓库收录「简历罗盘」产品的两套设计原型，全部为**纯静态 HTML**，零构建依赖、零外部请求，双击即可在浏览器打开。

| 原型库 | 数量 | 定位 |
|---|---|---|
| **落地页原型** `src/lp/` | 20 套 | 视差海报落地页。首屏抓注意力 → 特性带说清能力 → 收尾推动转化 |
| **功能页原型** `src/prototypes/` | 11 套 | 覆盖诊断、JD 匹配、逐条改写、支付等完整用户流程 |

### 落地页的 20 套视觉语言

## 快速开始（Docker）

需要 Docker 20.10+ 与 Docker Compose v2。

```bash
# 启动（首次会自动构建镜像）
docker compose up -d --build

# 查看日志
docker compose logs -f

# 停止
docker compose down
```

启动后访问 **<http://localhost:7999>**

| 路径 | 内容 |
|---|---|
| `/` | 站点导航页 |
| `/lp/` | 落地页原型总览（20 套，含实时缩略图） |
| `/prototypes/` | 功能页原型总览（11 套） |

### 镜像源加速（按需，由构建机配置）

Dockerfile 中的基础镜像（`alpine:3.20`、`nginx:1.27-alpine`）使用**规范的上游地址**，镜像源的解析交给构建环境，不写死在 Dockerfile 里。这样仓库在任何机器、任何 CI 上都可移植，且镜像来源元数据保持为规范的 Docker Hub 地址。

国内网络拉取慢时，在**构建机**上配置镜像加速即可，例如 `~/.docker/daemon.json`：

```json
{
  "registry-mirrors": ["https://docker.1ms.run"]
}
```

改完重启 Docker 生效。daemon 级配置带有回退能力——镜像源不可用时自动回落 Docker Hub；而写死在 `FROM` 里的前缀没有回退，源一旦失效所有构建都会失败。

> 供应链加固（可选）：生产环境可将基础镜像改为 `alpine:3.20@sha256:<digest>` 固定 digest。digest 是内容寻址的，无论经由哪个镜像源都能校验内容一致，可复现性更好；代价是升级基础镜像时需手动更新 digest。

### 不用 Docker 也能看

所有页面均为纯静态，直接打开或用任意静态服务器：

```bash
# 方式一：直接打开
open src/lp/00-index.html

# 方式二：本地起服务
python3 -m http.server 7999 --directory src
```

## 技术要点

### 视差引擎

20 套落地页共用同一份引擎代码（逐字一致），保证对比时只有视觉差异、没有实现差异。

- **双通道输入**：鼠标 `pointermove` 归一化到 `-1..1`，滚动 `scrollY` 截断到 `vh × 1.4`
- **单循环合并**：两路位移合进同一个 `requestAnimationFrame`，`lerp(cur, target, 0.075)` 做阻尼，产生惯性感
- **GPU 加速**：只用 `transform: translate3d()` 与 `will-change: transform`，不触碰会触发重排的属性
- **分层深度**：`--d-far .12` / `--d-mid .42` / `--d-near 1` / `--d-front 1.28`
- **无障碍降级**：`prefers-reduced-motion: reduce` 下跳过动画并取消 transform

### 构图系统

首屏用 `data-layout` 控制三档构图，把视觉主体推到 `--fx/--fy`，与文字块**永不重叠**：

```html
<section id="stage" data-layout="left">   <!-- 文字左 · 主体右 -->
<section id="stage" data-layout="right">  <!-- 文字右 · 主体左 -->
<section id="stage" data-layout="center"> <!-- 居中 · 主体下沉 -->
```

窄屏（≤860px）三档统一塌陷为「上文字 / 下主体」，避免移动端压字。

### 明暗主题

`data-tone="light|dark"` 驱动整页 CSS 变量翻转。4 套亮色主题（05 / 13 / 17 / 19）与 16 套暗色主题共享同一套组件样式，卡片表面色、投影、强调色透明阶全部随主题自动切换。

## 上线前建议

以下为原型阶段已知的待办，正式开发时需补齐：

- [ ] **无障碍**：补全 `aria-label`、键盘焦点顺序、对比度复核（尤其亮色主题）
- [ ] **性能**：20 套仅保留选中方案，避免全量打包；`iframe` 缩略图改懒加载 + 静态截图
- [ ] **SEO**：补 `meta description`、Open Graph 标签、结构化数据
- [ ] **埋点**：首屏停留时长、滚到特性带的比例、CTA 点击率
- [ ] **真实数据**：当前所有数字（匹配度、条数、天数）均为演示态文案
